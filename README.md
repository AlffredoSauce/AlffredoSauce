## Проекты

### Dumpling Store — DevOps Diploma Project

Дипломный проект Яндекс Практикума: развёртывание облачной инфраструктуры, контейнеризация приложения, организация CI/CD и автоматизация деплоя в Kubernetes.

Исходный код приложения предоставлен в рамках курса. Инфраструктурная и DevOps-часть выполнены мной. Проект был развёрнут на реальных облачных ресурсах; работающая инфраструктура и доступное извне приложение являлись частью требований дипломной работы.

**[Infrastructure](https://github.com/AlffredoSauce/dumpling-store-infra)** — Terraform, Yandex Cloud, Managed Kubernetes, VPC, Object Storage и remote state.

**[CI/CD & Kubernetes Deployment](https://github.com/AlffredoSauce/dumpling-store-deploy)** — Docker, GitLab CI/CD, Kaniko, Kubernetes manifests, Nginx и скрипты автоматизированного деплоя.
